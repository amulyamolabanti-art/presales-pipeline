REQUEST FOR PROPOSAL — SAMPLE EXCERPT
Document type: RFP
Section: 2.1 Technical Requirements

The proposed platform must support single sign-on (SSO) via Azure Active Directory (AAD).
All data must be encrypted at rest using AES-256 and in transit using TLS 1.3 or higher.
The system shall provide role-based access control (RBAC) with at least five configurable roles.
Audit logs must be retained for a minimum of 12 months and must be exportable in CSV format.
The solution should support multi-language UI (English mandatory; additional languages desirable).
Response SLA for critical incidents shall not exceed 1 hour.
The vendor must provide a disaster recovery plan with an RTO of less than 4 hours.
API documentation is preferred but not mandatory for V1 delivery.
Integration with Microsoft Teams for notifications would be advantageous.

Section: 3.0 Commercial Terms
Pricing must be presented on a per-user, per-month basis.
A fixed-price option is preferred for the implementation phase.
The vendor must have cyber-liability insurance of at least $5M USD.
