Your task is to design a complete Target-State Data Platform Architecture based on the provided RFP.

========================================================================
OBJECTIVE
========================================================================

Design a production-ready Target-State Data Platform Architecture.

The architecture must:

• Be Data Platform centric.
• Be implementation-focused.
• Be suitable for Enterprise Architecture review.
• Be suitable for HLD creation.
• Be suitable for solution estimation and planning.
• Be suitable for AI-generated architecture diagrams.
• Support Batch and Real-Time processing where applicable.
• Support CDC (Change Data Capture) where applicable.
• Support Event-Driven architectures where applicable.
• Support Hybrid Cloud where applicable.
• Support Multi-Cloud where applicable.
• Follow a strict LEFT-to-RIGHT architecture flow.
• Use technologies explicitly mentioned in the RFP.
• Infer only supporting services using industry-standard best practices.
